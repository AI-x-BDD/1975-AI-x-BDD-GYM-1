# Mini Issue Tracker

使用原生 JavaScript，透過 Vite 開發與建置。

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

建議使用 Node.js 22 LTS：先執行 `nvm use`（若已安裝 nvm）。
支援範圍以 package.json 的 engines 為準。

目前功能：輸入標題並按「新增」，建立狀態為「待辦」的任務。
空白標題會顯示錯誤；成功後清空輸入並保留輸入焦點。
任務清單即時顯示所有任務的標題與狀態；沒有任務時顯示「目前沒有任務」。
每筆任務可按「編輯」，預填原標題；儲存會移除前後空白，空白標題無法儲存。
取消會放棄草稿。編輯只改該筆標題，保留 ID、狀態與其他資料。
每筆任務可按「刪除」，原生確認對話框會指出任務標題；確認後永久刪除，取消則不變。
刪除最後一筆後會顯示空清單提示，不提供垃圾桶或復原。
可即時搜尋任務標題（部分符合、忽略英文大小寫與前後空白），並依全部、待辦、進行中、已完成篩選。
搜尋與狀態條件同時生效；「清除條件」恢復完整清單，並顯示符合筆數及無結果提示。
新增、編輯、刪除或切換狀態後會立即重新套用條件，隱藏任務的編輯草稿會保留。
任務只保存在記憶體中，重新載入頁面會清空，不使用 localStorage。

本地 Git 流程：短期功能分支，通過測試與建置後 fast-forward 回 main。
