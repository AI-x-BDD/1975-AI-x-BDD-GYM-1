# Feature 01：新增任務 — 原始 Prompt

請依序啟用以下三支 Skills：

/double-diamond-principle
/git-conventional-commit
/trunk-based-development

接著請幫我開發 Mini Issue Tracker 的第一個功能：**新增任務**。

需求：
- 使用者可以輸入任務標題。
- 點擊新增按鈕後建立任務。
- 標題不能為空白或只有空格。
- 新增成功後清空輸入欄位。
- 新任務預設狀態為待辦。
- 這次先使用記憶體狀態，不實作 localStorage。

開發要求：
1. 運用 Double Diamond 簡要探索問題、定義本次範圍、比較方案並設定驗收條件。
2. 遵守 TBD，將變更保持在小範圍，確保主幹維持可運作。
3. 補上必要測試，實際執行測試與建置。
4. 使用 Conventional Commits 建立合理的 Commit。
5. 依照專案的 Git 工作流程完成安全整合，不要擅自推送遠端或修改其他無關內容。
6. 將本次觀察資料記錄在 `docs/observations/feature-01.md`。

完成後請提供：
- Double Diamond 四階段摘要
- 實作內容
- 實際測試結果
- Git Branch 和整合狀態
- Commit Message 和 Hash
- 三支 Skills 的遵循證據
- 遇到的問題及優化建議

這次只完成第一個功能，不要提前開發其他功能。
