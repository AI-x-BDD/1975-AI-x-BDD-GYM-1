# Feature 02：顯示任務清單 — 原始 Prompt

請依序啟用以下三支 Skills：

/double-diamond-principle
/git-conventional-commit
/trunk-based-development

接著請幫我開發 Mini Issue Tracker 的第二個功能：**顯示任務清單（Task List）**。

### 功能需求
1. 使用者可以看到所有已建立的任務。
2. 每筆任務需要顯示任務標題與狀態。
3. 新增任務後，任務清單需要即時更新。
4. 當沒有任何任務時，顯示「目前沒有任務」。
5. 沿用第一個功能已建立的資料模型與記憶體狀態。
6. 不實作編輯、刪除、搜尋、篩選或 localStorage。

### 開發要求
1. 使用 Double Diamond 簡要探索需求、定義問題、比較方案，並建立驗收條件。
2. 遵守 TBD，保持小步變更，確認主幹維持可運作。
3. 補充必要的測試，實際執行測試與建置。
4. 使用 Conventional Commits 建立符合規範的提交紀錄。
5. 確保第一個「新增任務」功能仍然正常運作。
6. 將開發紀錄保存至 `docs/observations/feature-02.md`。

### 完成後請回報
- Double Diamond 四階段摘要
- 本次實作的內容
- 實際測試與建置結果
- Git Branch 與整合狀態
- Commit Message 與 Hash
- 三支 Skills 的實際遵循證據
- 發現的問題及改善空間

請只完成第二個功能，不要提前實作其他功能。
